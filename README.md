# Sri Rama Sanjeeva Traders (SRRS)

## 📋 Project Overview
A real-time web application developed for **Sri Rama Sanjeeva Traders** to display live wholesale prices for essential commodities including Garlic, Jute, Raida, Methi, Salt, and Copra. This platform serves as a digital price board for registered buyers in **Proddatur, Andhra Pradesh**, ensuring transparency and up-to-date market rates.

---

## ✨ Key Features
* **Live Price Board:** Real-time updates for wholesale commodity rates.
* **Inventory Status:** "In Stock" indicators for various quality grades (e.g., Grade A Fiber, Premium Quality).
* **Responsive UI:** A clean, gold-themed dashboard optimized for both desktop and mobile viewing.
* **Timestamped Updates:** Shows exactly when each price was last modified for buyer confidence.

---

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3 (Custom styling with a focus on cards and typography), and JavaScript.
* **Hosting:** Firebase (Google Web App).
* **Data Management:** Real-time synchronization for live price updates.
